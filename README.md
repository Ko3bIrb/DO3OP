# DO3OP

Standalone PC version of **Ночной дозор**, built with Godot 4.6.3.

This repository contains only the native Godot game. The browser version, web assets, and Three.js files are intentionally excluded.

## Run

Open `godot/project.godot` in Godot 4.6.3 and press F6/F5. No internet, npm, or web server is required.

For a Windows build, use the included export preset or download the GitHub Actions artifact after the repository is created.
