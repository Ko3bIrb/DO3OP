# Ночной дозор · Godot

Нативная игра на **Godot 4.6.3 Standard**, GDScript и рендерере **Forward+**.
Графическая версия рассчитана на ПК с поддержкой Vulkan. Браузерный проект сохранён отдельно.
Исходная версия для сравнения: `423218a9bdd971566c51c4cea87b2c29fbd8c3dc`.
Браузерная игра в корне репозитория продолжает работать независимо.

## Открыть и изменять игру

1. Установить [Godot 4.6.3 Standard](https://godotengine.org/download/archive/4.6.3-stable/) для своей ОС. .NET не нужен.
2. Скачать эту ветку репозитория или клонировать её.
3. В менеджере проектов Godot выбрать **Импортировать** → `godot/project.godot`.
4. Дождаться импорта моделей и нажать **F5**.

Для редактирования и запуска проекта не нужны npm, Three.js или веб-сервер.
Все модели, текстуры и звуки лежат в `assets/`. После установки Godot проект
можно открывать и запускать без интернета. Для готового `.exe` сам редактор тоже не нужен.

## Что перенесено

- Зимняя бухта с водопадом и вулканический Пепельный разлом с лавой и огнём.
- Шесть башен, три уровня каждой, строительство, улучшение и продажа.
- По десять противников и двадцать волн на каждой карте, способности боссов.
- Три сложности, экономика, тактическая пауза и темп от 0.25× до 5×.
- Меню, выбор карты, правила, звуки, локальные рекорды и звёзды.
- Мышь и касания; панель башни учитывает границы окна и магазин.

Это первая версия переноса для проверки. Игровые параметры сохранены из исходника.
Трёхмерные модели заново построены в Blender: материалы с фактурой и картами
нормалей, различимое оружие, доспехи, анатомия, подвижные конечности и крылья.
Это процедурная художественная версия, которой ещё потребуется ручная
доводка моделей и анимации; фотореализм не заявляется. Проверки логики не означают полного
совпадения изображения или проверки на всех компьютерах.
Сохранения браузера автоматически не переносятся.

## Управление

Выбрать башню в магазине → нажать на подсвеченную площадку.
Нажать на построенную башню → улучшить или продать рядом с ней.
Повторный выбор карточки отменяет строительство.
**Esc** открывает меню поверх текущей карты; повторное нажатие закрывает меню.
**Пробел** или кнопка **Пауза** включает тактическую паузу: бой и подготовка волн
стоят, строительство/улучшение/продажа доступны. Закрытие меню сохраняет прежнее
состояние тактической паузы.
Ползунок **ТЕМП** изменяет скорость от **0.25× до 5×**, двойной щелчок по нему
возвращает 1×. Кнопки ускорения заменены ползунком. Игра запускается во весь экран.
Короткое касание работает как щелчок;
перетаскивание, долгое касание и несколько пальцев не строят башню случайно.

## Где менять код

| Файл | Назначение |
| --- | --- |
| `scripts/main.gd` | Сцена, камера, интерфейс, управление, отображение эффектов |
| `scripts/simulation.gd` | Волны, бой, способности, экономика |
| `scripts/game_data.gd` | Загрузка параметров, расчёт уровней и цен |
| `data/game_data.json` | Карты, маршруты, башни, противники, волны |
| `scripts/save_store.gd` | Локальный прогресс в `user://progress.json` |
| `scripts/sound.gd` | Звуки |
| `assets/models/*.glb` | Модели для дальнейшего редактирования/замены через Blender |

Сцена входа — `scenes/main.tscn`. Для новых сложных карт можно постепенно
переносить декорации из общих GLB в отдельные редактируемые сцены Godot.

## Собрать Windows-версию

В Godot установить **шаблоны экспорта 4.6.3**, открыть **Проект → Экспорт →
Windows Desktop → Экспорт проекта** и выбрать `build/windows/NightWatch.exe`.
Режим отладки отключить. Готовый файл содержит игровые ресурсы внутри.
Рядом при распространении положить `LICENSE-GODOT.txt` и эту инструкцию.

Для сборки в терминале из корня репозитория:

```sh
godot --headless --path godot --editor --import --quit
mkdir -p godot/build/windows
godot --headless --path godot --export-release "Windows Desktop"
```

В GitHub Actions задача **Godot · Windows preview** собирает ZIP с `.exe`
для PR, затрагивающих `godot/`. Он доступен в разделе Artifacts завершённого
запуска (для скачивания артефактов нужен вход в GitHub). Это переносимая
предварительная сборка, установщик будет отдельным этапом. Сборка пока не
подписана цифровым сертификатом.

## Редактирование трёхмерной графики

Все новые GLB создаёт `tools/build_art.py` в **Blender 4.3+**:

```sh
blender --background --python godot/tools/build_art.py -- all
```

Вместо `all` можно указать `characters`, `towers`, `worlds` или `menu`.
GLB можно импортировать в Blender и редактировать вручную. Сцену меню,
каждый тип противника и каждый уровень башни можно править независимо.
**Повторная генерация перезаписывает GLB** — ручные варианты сохраняйте
в отдельных файлах. `data/asset_manifest.json` содержит контрольные суммы.

Материалы металла, камня, дерева, кожи, ткани, льда и снега имеют встроенные
текстуры и normal map; внешние файлы из интернета не загружаются. Маршруты,
ограничения площадок и боевые параметры при художественной переработке сохранены.
Имена узлов `turret` и `motion_*` используются кодом поворота и анимации.

Освещение, тени, снег/пепел, туман и мягкое свечение настраиваются в
`scripts/atmosphere.gd`. Зимняя карта — сумерки и тёплые фонари, ад — ночной
базальтовый ландшафт с локальными углями. Главное меню и меню паузы используют зимнюю художественную иллюстрацию
одинокого рыцаря, созданную с помощью генерации изображений, и отдельный
анимированный слой снега. Это иллюстрация, а не изображение игрового процесса.
В `menu_winter.glb` сохранён также трёхмерный прототип сцены для дальнейшей
ручной доработки в Blender.

`tools/convert_assets.cjs` и прежний фон меню оставлены как исходные материалы
первой версии переноса. Старый конвертер восстанавливает **прежние** модели,
поэтому для новой графики используется Blender-скрипт выше.

## Карты, эффекты и производительность

`tools/landscape.py` задаёт связный рельеф и сюжетные ориентиры: зимнюю бухту
с водопадом, островной дозорной площадкой, мостом, лагерем и поселением;
вулканическую чашу с лавой, огнём, руинами и останками дракона.
Лес и камни размещаются группами с разными размерами и поворотами и отображаются
через MultiMesh. `data/landscapes.json` хранит состав сцены и точки освещения.
Четыре зимние площадки перенесены с воды на береговые уступы; маршрут сохранён.

`shaders/terrain.gdshader` смешивает снег и камень по уклону,
`shaders/landscape.gdshader` анимирует воду, водопад и лаву.
Иллюстрации выбора карт созданы генератором изображений; это концепт-арт,
а не скриншоты игрового процесса.

`combat_fx.gd` повторно использует четыре MultiMesh с общими материалами для
вспышек, трассеров, дыма, ударов, искр и наград. Число частиц ограничено.
Модели врагов, полоски здоровья и варианты башен загружаются и прогреваются
за экраном подготовки карты. Смерть не переключает материалы в прозрачный
режим: тело падает, остаётся ненадолго и оседает; духи рассеиваются.
Анимация процедурная, не физический ragdoll.

Звуки выстрелов синтезированы заранее, голосовые MP3 преобразованы в PCM WAV
для воспроизведения без декодирования в бою. Для повторного преобразования:

```sh
ffmpeg -i audio/the_monster_roar.mp3 -ac 1 -ar 22050 godot/assets/audio/the_monster_roar.wav
```

Масштабирование Expand заполняет экран без полос на 16:9, 21:9 и других
соотношениях сторон. При переименовании игры прежний `progress.json`
из каталога «Защитник» читается автоматически, если нового сохранения ещё нет.
