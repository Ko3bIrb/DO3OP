# Dozor

Unity 6.6 RTS prototype. The project contains the current playable test: cone units, selection by click and rectangle, movement, camera controls, attacks, castle health, capture zones, resources, unit production, population limit, castle upgrade and victory/defeat.

## Open the project

Use Unity `6000.6.8f1` from `ProjectSettings/ProjectVersion.txt`. Open the scene:

```text
Assets/Scenes/GlobalMap.unity
```

## Controls

- WASD / arrow keys: move camera
- mouse wheel: zoom
- left click / drag: select units
- right click: move or attack
